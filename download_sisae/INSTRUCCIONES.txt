SISTEMA SISAE - INSTRUCCIONES DE INSTALACIÓN
=====================================================

REQUISITOS PREVIOS:
- Node.js 18+ instalado
- PostgreSQL instalado
- Git (opcional)

PASOS PARA INSTALAR:

1. INSTALAR DEPENDENCIAS:
   npm install

2. CONFIGURAR BASE DE DATOS:
   - Crear una base de datos PostgreSQL
   - Configurar variable de entorno DATABASE_URL
   - Ejemplo: DATABASE_URL="postgresql://usuario:password@localhost:5432/sisae_db"

3. CONFIGURAR VARIABLES DE ENTORNO:
   Crear archivo .env con:
   DATABASE_URL="tu_conexión_postgresql"
   SESSION_SECRET="tu_clave_secreta"

4. EJECUTAR MIGRACIONES:
   npm run db:push

5. INICIAR APLICACIÓN:
   npm run dev

6. ACCEDER A LA APLICACIÓN:
   http://localhost:5000

ESTRUCTURA DEL PROYECTO:
- server/ - Código del backend (API REST)
- client/src/ - Código del frontend (React)
- shared/ - Esquemas compartidos (tipos de datos)
- backups/ - Respaldos de datos existentes

TECNOLOGÍAS UTILIZADAS:
- Backend: Node.js + Express + TypeScript
- Frontend: React + TypeScript + Vite
- Base de datos: PostgreSQL + Drizzle ORM
- UI: Tailwind CSS + shadcn/ui
- Autenticación: Passport.js

FUNCIONALIDADES PRINCIPALES:
- Gestión de sanciones de clubes
- Gestión de sanciones personales (Tribuna Segura)
- Sistema de respaldos automáticos
- Reportes y estadísticas
- Subida de archivos PDF
- Panel de administración
